# Rally the Troops!

This is a local development server for building and testing RTT game modules.

## Getting started

- [Titles](titles) &mdash; browse the game modules that are installed on this server
- [Games](games) &mdash; list of games in progress

## Development notes

This server was cloned from `git.rally-the-troops.com/common/server`.
Game modules live in `public/<title_id>/` and are registered with a `title.sql` file.
