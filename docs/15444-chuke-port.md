# 15444《丘克群岛》港口光环（2026-10-23，两轮修复）

> 卡面：**`<硫磺岛>` 视为日本港口。计分阶段：若 `<硫磺岛>` 相邻地区都有日本海军，获得 1 分。**

---

## 一、最终语义

**港口 = 补给设施**，对海军同时满足两条条件：

| 条件 | 含义 | 港口如何满足 |
|---|---|---|
| **B** | 港口（= 相邻有本国陆军） | ✅ 该格视为有本国陆军 |
| **A** | 来源（能连回补给/补给源） | ✅ 港口本身即补给来源 |

但仍**不**让该格真的算"有陆军"：
- 不参与陆军补给续链
- 不满足"某地有日本陆军"类条件
- 不会被 `list_pieces` 数成陆军

敌占（该格被敌方部队占据）时整体失效。

---

## 二、两轮修复史

### 第一轮：`virtual_army` → `port_as`（修"建海军不生效"）

原实现 `kind: 'virtual_army'`（临时往 `game.location` 注入一支虚拟陆军）：

| 路径 | 结果 | 原因 |
|---|---|---|
| 海军补给（`compute_supply` 内） | ✅ 生效 | 注入此时还在 |
| **建海军**（`compute_supply` 之后） | ❌ **不生效** | 注入已在函数返回时清理 |
| 副作用 | ⚠ `sources` 冒出 `__varmy_48='base'`；虚拟陆军参与陆军续链 | 超出"港口"语义 |

于是改为 `status_aura.port_as` + `navy_ab_check` 显式判定，并删除注入。

### 第二轮：港口还要给 A（修"仍然没有相邻海域"）

第一轮只让港口满足 **B**，玩家实测**相邻海域依旧不可建**。

根因：硫磺岛是**荒岛**——不是初始补给点，相邻只有海域（陆军续链不可能），
所以 **A 永远不成立**，本卡在"建海军/海军补给"上等于无效。

修正：港口**同时给 A**（港口本身就是补给设施）。这才是"视为港口"的字面作用。

## 三、实现

```js
/* navy_ab_check：建海军与海军补给的唯一 A/B 判定点 */
const portAs = (game.status_aura && game.status_aura.port_as) || {}
for (const nb of list) {
	if (portAs[nb] != null && String(portAs[nb]) === String(nation) &&
		!has_pieces(game, { space: Number(nb), enemyOf: nation })) {
		hasLand = true      // B：港口
		hasSrc = true       // A：港口即补给来源
	}
	for (const other of pieces_on(game, nb)) { ... }
}
```

放在 `navy_ab_check` 而不是继续注入虚拟部队，是因为它是
**建海军**（`_build_piece_impl`）与**海军补给**（`compute_supply`）的**唯一**判定点 ——
一处改动两条路径同时生效。

## 四、改动清单

| # | 位置 | 改动 |
|---|---|---|
| 1 | `status_aura()` | 新增 `port_as`；惰性迁移旧 `virtual_army` → `port_as`（老对局无需重开） |
| 2 | `apply_status_ongoing` | `kind:'port'` → 写 `aura.port_as[sp] = nation` |
| 3 | `revert_status_ongoing` | 同步清 `port_as` |
| 4 | `navy_ab_check` | 港口判定：A+B 同时满足，敌占失效 |
| 5 | `compute_supply` | 删除虚拟陆军注入段与清理段 |
| 6 | 15444 配置 | `kind:'port'`，desc 改「视为日本港口」 |

## 五、影响面

| 项 | 变化 |
|---|---|
| 建海军（中太平洋 / 东海 / 北太平洋） | ✅ 硫磺岛空无一物也能建（港口提供 A+B） |
| 海军补给 | ✅ 该 3 个海域的日本海军始终在补给 |
| 只对卡归属国（日本）生效 | ✅ 英/美海军不受照顾 |
| 硫磺岛算"有陆军" | ❌ 不算（不污染 `list_pieces` 与陆军续链） |
| `sources` 脏键 `__varmy_*` | ✅ 消失 |
| 计分（相邻都有日本海军 +1） | ✅ 不变（独立逻辑） |
| 敌占失效 | ✅ 保持 |
| 撤销卡后 | ✅ 立即失效 |

全库只有 15444 用过 `virtual_army`（1 处配置），无其它卡依赖。

## 七、回修入口

| 症状 | 先看 |
|---|---|
| 硫磺岛相邻海域仍不能建海军 | `status_aura.port_as` 是否写入；`navy_ab_check` 里 `hasSrc = true` 那一行是否还在 |
| 硫磺岛被敌方占领后仍生效 | `navy_ab_check` 的 `has_pieces({space, enemyOf})` 守卫 |
| 硫磺岛被当成"有陆军" | 是否有残留 `virtual_army` 注入（应为 0） |
| 老对局里 15444 无效果 | `status_aura()` 的惰性迁移是否执行到 |
| 觉得"港口给 A"过强 | 改回只给 B 会导致本卡在荒岛上完全无效（第一轮已实测） |
