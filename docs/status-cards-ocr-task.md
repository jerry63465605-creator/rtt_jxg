## 3. 读图时必须遵守的项目口径

### 3.1 卡牌类型看右上角图标

| 图标 | 类型 |
|---|---|
| `!` | 事件卡 EVENT |
| `↑` | 增强卡 EFFECT |
| `?` | 响应卡 RESPONSE |
| 双箭头向上（形如两个叠起来的上升箭头） | **状态卡 STATUS** ← 本次处理的对象 |
| 兵器 | 经济战卡 ECON |

如果发现某张"状态卡"右上角图标**不是**状态卡的那种双箭头，请明确指出 ——
那说明类型判定也错了。

### 3.2 游戏只有 7 个阶段（按回合内顺序）

```
资源再分配 → 出牌阶段 → 空军阶段 → 补给阶段 → 计分阶段 → 弃牌阶段 → 抓牌阶段
```

判断"某某阶段开始时 / 某某阶段："时，只能落到这 7 个之一。

### 3.3 尖括号里的 `<英国>` 是占位符，不是固定指英国

卡面上写在尖括号里的国家名（尤其 `<英国>`）是**占位符**，
实际含义是"打出这张卡的持有国"。请把卡面原文照抄，
但在【国籍限定】里说明"此处为占位符，实现时按持有国解释"。

### 3.4 地名必须原样抄，不要替我翻译成本体名

本项目有"本体名 / 别称"两套叫法，**由我来做映射，你不要替我改**：

| 别称 | 本体名（地图上的实际地区） |

| 德国（指地块时） | 日耳曼 |
| 法国（指地块时） | 西欧 |

## 5. 我最需要你帮我定死的几个歧义点

这几条 OCR 文本完全表达不出来，但写代码时必须知道：

1. **状态卡打出后留在桌面，会不会被移出？**
   卡面有没有写"弃置此卡""回合结束时移除""保留至本回合结束"之类的话？

2. **"跳过出牌阶段行动"到底跳什么？**
   是指"打出这张卡之后，本回合出牌阶段不能再出牌"，
   还是"打出这张卡本身不占出牌名额"？

3. **"一回合一次"（15339）的计时单位**
   是"每个自己的回合一次"，还是"包含对手回合的一整轮一次"？

4. **可消耗发动的效果，用完要不要弃掉这张状态卡？**
   例如 15338 / 15341 / 15345 / 15347 这种"放弃 X：做 Y"，
   发动之后状态卡还在桌上吗？还是立刻进弃牌堆？

5. **"建造/建设"与"征召"是两个不同动作**
   本项目里"建设"要求大本营或邻接补给部队、且新部队保证补给；
   "征召"则没有位置要求、也不保证补给。卡面写的是"征召"还是"建设"？
   **务必分清。**
