# B27：SUPP（增援）牌库 37 张正式入池

> 日期：2026-11-07　范围：`rules.js`（1 行判定 + 注释）　影响：六国初始牌堆构成

## 1. 玩家报障

> 「我好像有很多卡很多局都没见过 —— 开一局真实盘面，读真实卡库+手牌来判断。」

实测（`tools/_audit_deck_pool.js` + `tools/_mk_board_real.js`）：

```
六国牌堆合计 368 张；全池不同牌面 326 种
cards.js 全表 446 张 → 120 张永远不出现
   = SUPP 37（已实装 100%）+ PRELUDE 76（未实装）+ ARMAMENT 7（未实装）
```

根因一行（`rules.js` `init_nation_deck()`）：

```js
if (c.deck !== 'CORE') continue      // SUPP/PRELUDE/ARMAMENT 全被跳过
```

配合原注释「SUPP 牌堆（增援）暂不混入核心牌堆，待规则明确后处理」——
即这 37 张**实现了却从不发牌**，每局可见池只有 326/446 = 73%。

## 2. 改法（玩家裁定：让 SUPP 进牌堆）

```js
/* CORE 与 SUPP 入池；PRELUDE / ARMAMENT 尚未实装，继续排除 */
if (c.deck !== 'CORE' && c.deck !== 'SUPP') continue
```

- 非 BASIC 各 1 张，**不改动** `BASIC_CARD_COUNTS` 的复制规则；
- PRELUDE / ARMAMENT 仍排除（它们还没实装，放进去等于发死牌）。

## 6. 行为变化（要跟玩家说明）

1. **SUPP 37 张现在会正常抽到**（每国 +3~12 张，牌堆变厚 → 关键卡抽到率略降）；
2. 前奏/武备仍不出现（未实装）；
3. 旧对局（已落库的 game 8~12）牌堆是**旧构成**，不会自动补 SUPP；
   想让老局也带上，只能新建对局（本次已用新构成重建 game 12）。

## 7. 边界

- SUPP 里少数卡依赖 `scenario`/特殊条件（如 16302 诺曼底登陆要求西线条件），
  抽到后可能因条件不满足暂时打不出——这与 CORE 卡一致（不是"入池"引入的新问题）；
- 若后续要按剧本/选项开关 SUPP（而不是默认全开），可在 `init_nation_deck` 里加 `options.supp` 判定，
  默认值保持现在的"开"。
