### A3. `run()` 函数式事件卡【无交互】——16 张，其中 7 张卡面明确要玩家选择

事件卡有两套实现：**声明式** `steps`/`choice`（会逐步询问玩家）与
**函数式** `run(game, ctx)`（**完全绕过询问框架**，打出即自动执行）。
`run()` 式共 **16 张**，全部拿不到任何交互能力。

**其中卡面明确写了"选择/或/1或2"，实现却没有交互的 7 张**（详见 `pitfalls.md` R45）：

| 卡 | 缺失的交互 | 严重度 |
|---|---|---|
| **15231 进攻美国** | 卡面"对相邻地区发起 **1或2次** 陆战"，实现却**遍历全部相邻**（打多了） | 🔴 规则错误 |
| 15226 巴巴罗萨 | "**选择** 3 支苏联陆军，按**任意顺序**" | 🔴 需选 3 个目标+定序 |
| 14503 提尔比茨号 | "英国**选择**并暗牌弃置 1 张响应" | 🟠 需对方玩家选 |
| 15229 生产构思 | "检视牌堆，**选择**并打出 1 张[状态卡]" | 🟠 需选牌 |
| 15239 战略规划 | "**选择** 2 张牌…弃置 1 张手牌" | 🟠 需选牌（两处） |
| 15238 伊卡鲁斯行动 | "在<冰岛>**或**<亚速尔>征召" | 🟡 需选地区 |
| 15236 瑞典支援芬兰 | "可打出 1 张[北方行动]" | 🟡 可选追加 |

**已确认的同类（用户点名，结论）**：
- 15317 史末资：声明式，**已随 R44 修复** ✅
- 15225 阿登闪击战 / 15230 海狮计划：地区固定，自动执行**可接受**（但失败时静默，体验差）

**根治方案**：把这些卡改写成声明式，或给 `run()` 加一层"需要哪些选择"的描述。
