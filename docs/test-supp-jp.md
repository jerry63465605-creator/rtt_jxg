## 2. 逐卡实测

### 7900《竭泽而渔》（弃 4 张手牌 → 从弃牌堆取 1 张）

```
驱动（三段真实动作）：
  play_card{card}                          → 「《竭泽而渔》：选择 4 张手牌弃置」
  resolve_script{discard:[4 个实例 id]}     → 「【日本】弃置 4 张手牌 | 检视弃牌堆，选择 1 张置入手牌」
  resolve_script{pick:[候选实例 id]}        → 手牌 +1、脚本结束
断言：手牌 11 → 10（卡离手）→ 6（弃 4）→ 7（取回 1）✓
```

> 参数键：**弃牌用 `discard`、取牌用 `pick`**（不是 pīck 一把梭）。
> 候选对象结构 = `{ id:'7903#1'(实例), card_id:'7903'(牌面), name, type, nation }`
> → 提交必须用 **`id`**（用 `card_id` 会得到「7903 不是合法候选」）。

### 7901《强占马六甲海峡》（ECON）

```
布阵：日本陆军在<东南亚> + 日本海军在相邻海域
驱动：play_card{card, target:'英国'}
日志：东南亚有日陆军且相邻有日海军：英国损耗 2 张，日本+2分
断言：英国牌库 69→67 ✓　axis 0→2 ✓
对照：撤掉相邻海军 → 「条件不满足…无效果」，英国牌库不变 ✓
```

### 7902《澳洲海岸线攻势》（RESPONSE）

```
暗置：真实 play_card 可把 7902 放到桌面（table_responses）✓
判据：filter(日本 对澳)=true｜filter(英国 对澳)=false｜filter(日本 对东南亚)=false｜filter(日本 对新西兰)=true ✓
```

> **地图事实**（写进结论）：`<澳大利亚>` 只与 印度洋/南海/南太平洋 相邻，`<新西兰>` 只与 南太平洋/东太平洋 相邻

> 若将来出现“海军陆战/跨海登陆”机制，需要补一条真实战斗链路。

## 3. 本轮新增的 4 条测试手法（日系卡特有）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | `play_card{card, drop:[...]}` 对**非 armed** 的 EFFECT 无效 | 代价在脚本里分步付：`resolve_script{discard:[...]}` |
| 2 | 脚本候选里 `card_id` 是牌面、`id` 才是实例 | 提交用 `id`；`view`/`query` 两处都要按此归一 |
| 3 | play_start 响应卡要**先暗置再重进出牌阶段** | `play_card`（暗置）→ `debug_set_phase(resource)` → `debug_set_phase(play)` |
| 4 | `<澳大利亚>/<新西兰>` 只邻海域 → 无法陆地开战 | 这类卡只能验 `trigger.filter`，别硬造陆战（会得到「没有处于补给状态的本国陆军或海军相邻」） |
