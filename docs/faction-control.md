## 对 RTT 实现的影响

因为只有 **2 个玩家位**，RTT 的 `exports.roles` 应为：

```javascript
exports.roles = ["Axis", "Allies"]
```

而 6 个"行动顺序"国家（德英日苏意美）是**回合内部**的轮转，不是 RTT 的 role。这一点必须在 `rules.js` 里区分：

- **RTT role**（2 个）：Axis / Allies —— 决定谁能看到手牌、谁能操作
- **行动顺序国家**（6 个）：在轴心/同盟各自的手牌与部队范围内轮转

法国、中国没有独立的"回合"，其部队由操控方的玩家在**自己的回合/阶段**内指挥。
