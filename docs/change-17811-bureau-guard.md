# 17811《雅科夫列夫设计局》特例：抵消后「原地补机保护陆军」

> 日期：2026-11-06　范围：`rules.js`（服务端）　相关卡：17811（苏联增强卡）

## 1. 背景与口径

- 卡面：「苏联空军被移除后：在该地区或相邻地区部署或调度 1 支苏联空军。」
- 玩家口径（本次）：
  - 一次**陆战**中，防守方选「空军代受」、进攻方选「抵消」时，
    若防守方手里有 17811 且能在**原地**部署，应当**直接询问**是否用新飞机保护这支陆军；
  - 新机代受后，**进攻方仍可再抵消**（消耗其另一支相邻空军）；
  - 只有进攻方**不再抵消**时，新机才算"保护成功"（新机死、陆军活）；
  - 其它空军死亡窗口（15351/15311/17808/响应卡等）**照常派发**，不受影响。

## 2. 触发条件（4 条同时满足才进特例）

| 条件 | 说明 |
|---|---|
| `kind === 'land'` | 仅陆战（海战一律走原逻辑） |
| `!is_protected(victim)` | 陆军未被 15330/15334/15410 等保护 |
| `bureau_card_for(vNation)` 非空 | 防守方**手里有** 17811 |
| `su_air_deploy_spaces(game, space)` 含 `space` | **原地**可部署空军 |

任一不满足 → **逐字节走原逻辑**（victim 立即移除、派发三路窗口）。

## 3. 状态机

```
counter（抵消成立）
   ↓ 4 条满足
bureau_wait（victim 暂不删、不派发；depth+1，上限 2）
   ↓ 窗口/响应栈都空 → maybe_ask_bureau
   ① 原地已出现新机（不在 air_used）→ defend(新机, bureau_again)
        ├ 防守方不代受 → victim 移除（新机留在原地）
        └ 防守方代受 → counter（候选排除 air_used）
              ├ 进攻方不抵消 → 代受成立：新机死、★陆军保住★（结束）
              └ 进攻方抵消   → 双方各死 1 架 → 回 bureau_wait（depth+1）
                                 · depth ≤ 2 且仍有 17811 → 再问
                                 · 否则 → victim 移除
   ② 尚未问过 17811 且仍可用 → 开 17811 窗口（只此一次）
   ③ 已问过且无新机 → victim 移除（原三路派发 + battle 钩子）
```

## 4. 生死表

| 情形 | 新机 | 进攻方第二架 | 陆军 |
|---|---|---|---|
| 补机后进攻方**不**抵消 | 死 | — | **活** |
| 补机后进攻方**再**抵消 | 死 | 死 | 死（再回 bureau_wait，看是否还有 17811） |
| 补在**相邻地区** | 活 | — | 死（不算保护） |
| 不发动 17811 | — | — | 死 |

## 5. 实现要点

| 函数 | 作用 |
|---|---|
| `bureau_card_for(game, nation)` | 在防守方手里找 17811 实例 |
| `strip_bureau_offers(game)` | 进特例前把 17811 从"空军死亡窗口"里摘掉，避免问两次 |
| `maybe_ask_bureau(game)` | 挂在 `exports.action` 出口（在 `flush_piece_removed_offers` 之后）：<br>窗口/响应栈/队列都空时才推进三步（进 defend / 开窗口 / 收尾） |
| `finalize_victim_after_bureau(game, pb)` | 收尾：按原逻辑删 victim（三路派发 + `battle` 钩子 `deferToTail`） |
| `air_used` / `bureau_depth` | 记录用过的空军与递归深度，防重复、防死循环 |

动作门禁：`stage === 'bureau_wait'` 期间只放行
`use_armed_offer / skip_armed_offer / resolve_battle / log / debug_*`。

## 6. 边界

- **上限 2 次补机**（`bureau_depth <= 2`），避免"多张 17811 + 多支空军"无限循环；
- 17811 被 15343 压制 / 手牌不足 / 原地无载体 → 不进特例；
- 该特例只处理"保护本次陆军"，**不复活**已被移除的空军（空军实例仍是 `delete` + 新建）。
