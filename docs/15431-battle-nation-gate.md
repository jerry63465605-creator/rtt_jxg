# battle 型响应卡缺"发起国"限定（15431 全面侵华为代表，共 5 张）

> 状态：**✅ 已修复（2026-10-25，工作区未提交）**
> 验证：`node tools/_smoke_a1a2.js` —— 5 张卡的"日本发起 → 触发 / 他国发起 → 不触发"全部 PASS，
>      另加 15430《奇袭》回归 PASS。
> 结论：不是效果写错，而是**触发条件漏了一个 `ctx.nation`**。

## 一、现象与正确口径

15431《全面侵华》卡面：

> 对 `<中国>` 发起陆战后：在战斗地区建设陆军。对相邻地区发起 1 次陆战。

这是**日本视角**的卡，只有**日本**对 `<中国>` 发起陆战时才该触发。
当前实现只判"陆战 + 地区在中国"，于是**任何国家**在中国地区发起陆战都会触发它 ——
包括苏联 17821 对 `<中国东北>` 发起陆战、英国从印度方向打 `<中国>` 等。

效果侧本身没有问题（14685 里建设写死 `'日本'`、再战走 `pick_space_then_battle` 自动取日本单位），
所以现在的表现是：**苏联打中国，日本却在那个地区建陆军并再打一次**。

## 二、根因

```14135:14141:server-official/public/quartermaster-sub-wars/rules.js
	'15431': {
		name: '全面侵华', actor: '日本',
		trigger: {
			on: 'battle',
			filter: (g, ctx) => ctx.kind === 'land' && is_in_region(ctx.space, '中国'),
		},
	},
```

同表里已有正确写法可对照：

```14113:14113:server-official/public/quartermaster-sub-wars/rules.js
		trigger: { on: 'battle', filter: (g, ctx) => ctx.kind === 'sea' && ctx.nation === '日本' },
```

`battle` 事件的 ctx 自带 `nation`（发起国，见 18172/18636/18773 三处派发），所以判定成本为零。

## 四、修复

5 处 filter 各加一个与条件：

```js
filter: (g, ctx) => ctx.kind === 'land' && ctx.nation === '日本' && is_in_region(ctx.space, '中国'),
```

`ctx.nation` 与 `g` 参数当前在这些 filter 里未使用，无需其它改动。

## 五、验收

1. 苏联 17821 对 `<中国东北>` 发起陆战 → 日本 15431 **不**触发（`response_stack` 无该帧）
2. 日本对中国地区发起陆战 → 15431 正常触发，仍能"在战斗地区建设陆军 + 选相邻地区再战"
3. 15422 / 15435 / 15437 / 7902 各自按"本国发起"判定，敌方同类地区战斗不再误触发
4. 15336（法国友方）行为不变
5. 回归 `_smoke_jp_response.js` / `_smoke_italy_response.js`

## 六、风险

- 改动 5 行，全是 filter 收窄，不会误伤效果实现
- 唯一可能的变化：以前"别国帮忙触发"的场面消失 —— 这正是本次要修的
