## 3. 三套机制

### 3.1 打出（占出牌名额 → A1①）

`play_card` 新增 STATUS 分支：

1. 校验在出牌阶段（否则拒绝）
2. 执行 `ongoing.on_play`（如 15344 的即时征召）
3. 执行 `ongoing.apply`（光环写入 / 地图改动写入）
4. 推入 `game.table[nation]`（正面朝上）
5. `mark_play_done` —— 占三选一名额

### 3.2 持续效果（A4①：光环随卡，地图改动永久）

| 类型 | apply | 离场处理 |
|---|---|---|
| **光环**：15346 法国总在补给 | `game.status_aura.supply_immune['法国'] = card_id` | **回滚**（删键） |
| **光环**：15344 大本营改判 | `game.status_aura.home_override['法国'] = '不列颠'`（条件：西欧被敌方控制） | **回滚** |
| **光环**：15343 敌方状态卡无效 | **不写入**，动态查询 | 无（离场自动失效） |
| **地图改动**：15345/15347 补给点 | `add_supply_point(game, space, faction)` | **不回滚（永久）** |
| **地图改动**：15345/15347 计分标记 | `add_marker(game, space, n, owner)`（owner=法国/英国，S1） | **不回滚（永久）** |

**15343 用派生式而非写入**：判断某张状态卡是否生效时，扫桌面看有无敌方 15343。
天然满足 B1②「卡在桌上期间每个自己回合内有效」，无需维护开关。

### 3.3 触发效果（点击状态牌 → A2）

扩展现有 `card_triggers_ready()`，窗口四种：

| 窗口 | 卡 | 说明 |
|---|---|---|
| `play_start` | 15338、15345、15347、15348 | 自己回合出牌阶段开始时 |
| `after_naval` | 15339（一回合一次） | 发起海战后（B6②） |
| `build_army` | 15341、15342 | 打建设卡时，点状态牌放弃建设（S4） |
| `after_ally_battle` | 15346 | 英/美发起战斗后，点状态牌让法国再打一次（B3②） |

代价统一处理：
- `skip_play` —— 本回合不再出牌（标记 `game.skip_play_done[nation]`）
- `discard: N` —— 弃 N 张手牌（需 UI 选牌）
- `forgo_build_army` —— 放弃本次建设，改为执行状态牌效果
- `lose_score: N` —— 自己阵营 -N（S2①）

**触发后卡保留**（A3①）；`once_per_turn` 用 `game.status_used[card_id] = turn` 记频率。
