## 3. 本次修复：16801《哈尔西》/ 16802《麦克阿瑟》选了部队也没用

- **现象**：在客户端点地图选中部队后，窗口又回到「请选择一支部队」，永远打不出去 —— 典型"点了没反应"。
- **根因**：这两张卡的 `armed.run` 读 `arg.from`，而 `need:'piece'` 通道回传的字段名是 **`piece`**
  （`use_armed_offer` 的 `_sel` 只持久化 `piece/space/status/choice/drop/pick`；客户端 `play.js:11001` 也是发 `{card, piece}`）。
  → `arg.from` 永远为 null → 无限要求选部队。
- **修法**（2 处，最小改动）：`const _from = arg.from != null ? arg.from : arg.piece`，其余逻辑不动（兼容直接传 `from` 的调用方）。
- **验证**：`_real_test_supp_us.js` 第 7/8 组由 FAIL 转 PASS（日志出现第二次海战 / 第二次陆战）。

## 4. 16302《诺曼底登陆》为何只验"优雅失败"

卡面要求：**在<北海>建设1支海军** → 对<西欧>发起1次陆战。合成盘面上：
- 美国建海军@<北海> 需要"邻接本国（或组内盟国）的陆地部队" + 连回补给源 —— 美国开局无欧洲立足点；
- 陆战@<西欧> 需要相邻的补给中美军 —— 同样没有。

故本测试只断言：① 引擎给出明确原因（不是静默失败）；② **不死锁**（无 budget / 无分步 /
无 delegate / 无响应栈残留）。正例需要真实对局里美国已在欧洲登陆（如 game 12 那类盘面），
留待 `rtt-realboard-test` 路线 A 覆盖，已登记到 `docs/todo-2026-10-29.md`。

## 5. 本轮新增的 6 条测试手法（美系卡特有）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | 美国开局中立 → 打不了轴心、建不了<北海> | 布阵时显式 `g.neutral['美国'] = false`（若真要做"结束中立"流程，另用真实动作） |
| 2 | 桌面 17555《大萧条的余波》把每张美国事件/状态卡都打断 | 测试 SUPP 时先把它从桌面摘掉；要测该机制再单独测 |
| 3 | 美国本土离战场远，靠 `grant_supply` 拼不出"建设合法" | 用真实链：本土陆军→<东太平洋>海军→<夏威夷>陆军（夏威夷是补给点），此后<北太平洋>/<中太平洋>都可建 |
| 4 | 事件卡的**战斗步**不是立即结算 | `play_card` 后需 `event_step_next{}` 生成 `event_budget`，再 `event_battle{target, from, victim}`，最后 `event_finish{}` |
| 5 | `use_armed_offer` 的 `need:'piece'` 提交键是 **`piece`**（不是 `from`） | 断言脚本一律传 `piece`；服务端若读 `arg.from` 即契约 bug（本次 16801/16802 就是这样被抓到的） |
| 6 | 美国侧动作传 `'Axis'` 会被拒「现在轮到【美国】行动，轴心暂不能打牌」 | `R.action(g, side, ...)` 的 side 必须与 `current_nation` 同阵营：美国卡用 `'Allies'` |
