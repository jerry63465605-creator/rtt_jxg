## 2. 实测结算顺序

```

② event_battle{西欧} → 立刻结算陆战：
     【德国】在 西欧 进行陆战，移除敌方陆军（法国）
     【法国】陆军 从 西欧 移除
   西欧 = []                       ← 部队当场移除（不是"待移除"）
③ 同一时点产生两个独立窗口：
     pending_trigger = [15337 生命的飞跃]              （只有英国看得到）
     armed_offer     = [15351 ×N, 15311]  when='piece_removed'  owner=英国
④ 客户端串行渲染：
     update_pending_trigger_box() 先；update_armed_offer_box() 开头
     `if (view.pending_trigger || view.response_choice) return` 让位
⑤ 触发 15337 → **事后还原**（rules.js L17096-17105）：
     【响应】《生命的飞跃》触发：该法国陆军本回合不会被移除
     【法国】在 西欧 建设 1 支陆军       → 西欧 = ["法国/army"]，登记本回合 protect
     15337 进弃牌堆（桌面响应清空）
⑥ armed 窗口**不关闭**，响应框关掉后继续问：
     打出《敦刻尔克大撤退》（弃 2 张）／《马奇诺防线》（弃 4 张）／不打出
```
