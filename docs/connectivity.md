# 连通性规则（普通 / 有限 / 海峡动态）

> 版本 v1.0 · 2026-09-21 · 数据文件 `out/spaces_calibrated.json`
>
> 状态：**连通性结构已定稿并保存**，编译产物 `out/adjacency.json` 已生成。

---

## 1. 三种连通

| 类型 | 存档字段 | 含义 | 谁能用 |
|---|---|---|---|
| **普通连通** | `type: "normal"` | 双方都视为相邻 | 两阵营 |
| **有限连通** | `type: "limited"`, `side: "axis"\|"allies"` | 只对指定一方视为相邻 | 仅 `side` 指定的阵营 |
| **海峡连通** | 由 `points[].strait` 推导 | 动态：谁能用取决于**控制者** | 控制方 |

有限连通的 `note` 字段记录原因（`"海峡"` / `"某张牌"` / 具体牌名），仅作说明，不影响逻辑。

---

## 2. 海峡连通的定义（用户确认）

**海峡标记打在陆地格位上。** `strait: true` 的陆地格位表示：这块陆地上存在一条
海峡航道，航道两侧的两片海域（或海域与海岸目标）本来隔着陆地不连通，
控制这块陆地的人就能用这条航道。

```
        ┌─── 海域 A ───┐
        │              │
   ┌────┴────┐    ┌────┴────┐
   │ 海峡陆地 │    │         │      ← 海峡格位把 A 与 B 隔开
   │ strait  │    │         │
   └────┬────┘    └────┬────┘
        │              │
        └─── 海域 B ───┘
```

### 2.1 控制权判定

**判定顺序**（先算部队，再回落默认）：

1. 该海峡陆地格位上**有任何一方的部队** → 该方**控制**此海峡
   - 部队 → 国家 → 阵营映射：
     - 轴心国：德国、日本、意大利
     - 同盟国：英国、法国、苏联、美国、中国
   - 只按控制者阵营记，不关心具体是哪国部队
2. 格位上**没有部队** → 使用**开局默认归属**：

   | 海峡所在陆地 | 默认归属 |
   |---|---|
   | 北欧（丹麦海峡） | **轴心国** |
   | 非洲北部 | 同盟国 |
   | 中东 | 同盟国 |
   | 拉丁美洲 | 同盟国 |
   | （其余 `strait: true` 格位） | 同盟国 |

3. **同一格位不会同时存在双方部队**
   - 建设/征召的前提是"目标格位无敌方部队、无本国部队"
   - 因此不存在控制权归属不明确的中间态，控制权是**确定值**，每回合可刷新

> 关于"开局默认归属"：控制权是**动态派生值**，不需要在 game state 里存一份
> 可变的 owner（那会导致存档与撤销/重放不一致）。默认归属是 `getStraitController()`
> 在"格位上无部队"时的**兜底返回值**；一旦有部队进驻，就自然接管。

### 2.2 效果

对**控制方**：海峡两侧海域 `S1`、`S2` **视为相邻**（双向）。
对**非控制方**：`S1`、`S2` **视为不相邻**。

这是**阵营私有连通**：同一对海域，轴心国认为通、同盟国认为不通（或反之）。

**示例**（用户给出的场景）：
> 原本"北欧 ↔ 非洲北部"不连通。若轴心国控制北欧（丹麦海峡），
> 则北海—波罗的海（或其他被隔开的两片海域）对轴心国打通，
> 从而让轴心国的舰队/补给网络从北欧一路延伸到非洲北部。

## 3. 数据格式

### 3.1 格位（`points[]`）

```json
{ "name": "北欧", "x": 955, "y": 105,
  "terrain": "land", "supply": false, "home": false, "strait": true }
```

`strait: true` 表示该陆地格位上有一个海峡。

### 3.2 连线（`links[]`）

```json
{ "a": "北海", "b": "不列颠", "type": "normal", "side": null, "note": "" }
{ "a": "北海", "b": "南大西洋", "type": "limited", "side": "axis", "note": "丹麦海峡" }
```

> **海峡连线怎么连**：把海峡所隔开的**两片海域**直接连成一条
> `type: "limited"` 的线，`side` 先填默认控制方（北欧填 `axis`，其余填 `allies`），
> `note` 填 `"海峡"` 或海峡名。
> 运行时由 `getStraitController()` 决定这条线**实际**对哪一方生效，
> 存档里的 `side` 只作为开局默认值。

## 4. 运行时算法

### 4.1 单条连线是否可用

```
lineUsable(line, side):
    if line.type == "normal":           return true
    if line.type == "limited":
        if line is a strait line:       return getStraitController(line.straitSpace) == side
        else:                           return line.side == side
```

### 4.2 邻接表（按阵营生成）

```
buildAdjacency(side):
    adj = {}                             # space -> [space, ...]
    for line in allLines:
        if not lineUsable(line, side):   continue
        adj[line.a].push(line.b)
        adj[line.b].push(line.a)
    return adj
```

### 4.3 海峡控制者

```
getStraitController(space):
    units = unitsOn(space)               # 该格位上的所有部队
    if units is not empty:
        return factionOf(units[0].nation)          # 'axis' | 'allies'
    return space.strait_default_side or "allies"   # 兜底默认
```

### 4.4 使用场合

全规则里**所有**判断"相邻"的地方都改用 `buildAdjacency(side)`：

| 机制 | 说明 |
|---|---|
| 补给传播 | 从补给点 BFS 扩散，只走本阵营可用的边 |
| 战斗 | 只能攻击**本阵营视角下相邻**的地区 |
| 建设/征召 | "邻接处于补给状态的本国部队"用本阵营邻接 |
| 海军补给 | "与本国/友军陆地部队相邻"同样受阵营邻接影响 |
| 海峡控制权刷新 | 每回合补给阶段重算，因为部队位置可能变化 |

**关键约束**：连通性判断必须**带 side 参数**。
不能在初始化时构建一次全局邻接表，否则有限连通与海峡动态无法生效。

## 6. 编译产物 `out/adjacency.json`

由 `tools/build_adjacency.js` 从 `spaces_calibrated.json` 生成，可重复执行。

```bash
node tools/build_adjacency.js
```

结构：

```javascript
{
  meta:       { map, source, width, height, updated, counts },
  spaces:     { "北欧": { terrain, supply, home, strait, strait_default, x, y }, ... },
  adjacency:  { axis: { "北欧": ["北海","波罗的海","罗斯"], ... },
                allies: { ... } },
  straits:    [ { space:"北欧", default:"axis", a:"北海", b:"波罗的海", connected:true }, ... ],
  limited:    [ { a:"西欧", b:"非洲北部", side:"axis", note:"意大利控制直布罗陀" } ],
  components: { land, sea_axis, sea_allies },   // 连通块，便于调试
  warnings:   [ ... ]                            // 数据校验警告
}
```

**要点**：
- `adjacency.axis` 与 `adjacency.allies` **是两份不同的表**，因为有限连通与
  海峡动态会让同一对格位在一方相邻、另一方不相邻（当前有 8 个格位存在差异）。
- 邻居列表已去重并排序，保证输出**确定性**（便于 diff 与版本管理）。
- `warnings` 覆盖：重名格位、悬空引用、海峡缺 `note`、海峡未连线、
  海峡线连到陆地、有限连通缺 `side`。

## 7. 已确认的规则决策

1. **海峡连线连在两片"海—海"之间** ✅
2. **开局默认归属**：北欧=轴心，其余 3 个=同盟 ✅
3. **海峡只打通两片海域之间**，陆军不受影响（跨海仍需海运/两栖）✅
4. **岛国只有 1 度连接**：不列颠、日本只能靠海运/两栖登陆，不补连对岸陆地 ✅
5. **控制判据**：该陆地格位上有任何一方部队即由该方控制，不看是否大本营 ✅
6. **控制权是派生值**，不存入 game state（避免与撤销/重放冲突）✅
