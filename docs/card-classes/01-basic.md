# 01 基本卡 BASIC（30 张）

> **一句话判据**：`cards.js` 里 `type === 'BASIC'`，六国各 5 张，**不进牌堆、不进手牌池**，每国固定持有。

## 一、怎么认出这类卡

- `cards.js`：`type: 'BASIC'`，id 命名成段（`15200~15204` 德国、`15300~15304` 英国、
  `15400~15404` 日本、`17500~17504` 美国、`17700~17704` 意大利、`17800~17804` 苏联）
- `rules.js`：**没有** `EVENT_EFFECTS` / `ECHO_EFFECTS` 登记 → 靠 `resolve_basic_card` 的硬编码分支
- `_internal` 相关导出：`deck_basics` / `resolve_basic_card` / `basic_targets`

## 二、共性：五张一套

| # | 卡名 | 语义 | 关键约束 |
|---|---|---|---|
| 1 | 建设陆军 | 在**有补给、有载体**的陆地建 1 支陆军 | 同国同地区陆军上限 |
| 2 | 建设海军 | 在**港口/海区**建 1 支海军 | 目标区不能有敌方部队（见下） |
| 3 | 发起陆战 | 用相邻**陆/海军**打目标地区的敌方部队 | 目标必须是**陆地**（海域报错） |
| 4 | 发起海战 | 用相邻**海军**打海域目标 | 发起单位必须补给、必须是海军 |
| 5 | 空军力量 | 空袭 / 夺制空权 | 空军不能作为普通战斗的发起单位 |

这三条是卡面之外的**硬规则**，全部由 `play_card` 校验并写日志：

```
《发起陆战》无法执行：陆战的目标必须是陆地，而 北海 是海域
《建设海军》无法执行：北海 有敌方部队
《发起陆战》无法执行：指定的部队不是该地区的敌方部队
```

## 三、共性：调用链

```
play_card { card, space, piece }
  ↓
resolve_basic_card()
  ├─ basic_targets(game, ...)   ← 服务端算候选（客户端不自己算）
  └─ do_battle / build_piece / recruit_piece / 空军相关原子
  ↓
消耗出牌名额（play_done）、写日志、派发后续时点
```

**关键参数语义（最常写错）**：

| 参数 | 含义 |
|---|---|
| `card` | 基本卡的**实例 id**（`'15201#1'`），不是面 id |
| `space` | 目标地区 |
| `piece` | **被攻击的目标部队**（不是发起单位！） |
| `from` | 发起单位（部分路径支持，发起战斗时由服务端从 `battle_initiators` 取） |

> 写测试时最容易错：把 `piece` 当成"发起单位"传进去 → 日志「指定的部队不是该地区的敌方部队」。

## 四、共同易错点

| # | 坑 | 现象 |
|---|---|---|
| 1 | 发起陆战打**海区** | 「陆战的目标必须是陆地」—— 海区只能用"发起海战" |
| 2 | 发起海战时把陆军当选发起单位 | `battle_initiators` 只收 `army/navy`，海军目标要海军发起 |
| 3 | 目标区有敌方部队还去建设 | 「有敌方部队」，建设被拒 |
| 4 | 发起单位**断补** | 候选为空（`battle_initiators` 过滤 `in_supply`），前端看不到可点单位 |
| 5 | 把 `piece` 传成发起单位 | 见 §三 参数表 |
| 6 | 用基本卡当"万能效果" | 基本卡只做行动本身，**任何额外效果都不该塞进 `resolve_basic_card`** |

## 五、验收写法

基本卡不写单卡脚本，**归到两个公共套件**：

- `tools/test_basic_cards.js`（战斗 / 建设 / 空军全流程，含代受与撤退）
- 涉及补给、连通的用例走 `tools/_run_smoke_report.js` 里的通用脚本

断言口径：

```js
// 发起战斗必然先挂起（目标区有可代受空军时）
ok(!!g.pending_battle, '战斗被挂起，等防守方决定')
ok(g.pending_battle.defender_nation === '英国', '防守方正确')

// 不代受 -> 目标移除 + 空军撤退（撤退目标是"相邻 + 有本国载体"的地区）
ok(g.location['uk_army'] == null, '目标被移除')
ok(g.location['uk_air'] === retreatSpace, '空军撤到合法邻区')
```

## 六、参考实现

| 想做什么 | 看哪里 |
|---|---|
| 算出可发起战斗的单位 | `battle_initiators(game, nation, space)` |
| 算出空军可攻击的单位 | `air_initiators(...)` |
| 建设 / 征召 | `build_piece` / `recruit_piece` / `can_recruit_at` |
| 载体校验（空军能否进驻） | `air_host_check` / `unit_slot_free` |
| 战斗全流程 | `do_battle`（代受 → 抵消 → 撤离 → 移除 → 派发） |
