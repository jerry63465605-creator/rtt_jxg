# 15311《马奇诺防线》：按 B（待命增强卡）定案 + 排查记录

> 日期：2026-11-08　范围：`cards.js`（卡面文案）、`rules.js`（拒绝文案分支）
> 玩家口径：**按 B** —— 它就是"待命"卡，被事件触发时才询问，不改成可主动打出；
> 但同时反馈"英国无法打出该增强"，故先构建真实盘面排查。

## 1. 排查结论：**触发路径是通的，坏的只是文案**

真实盘面（德国对<西欧>发起陆战，移除法国陆军）：

```
窗口 = [{ when:'piece_removed', nation:'英国', cards:[15351 敦刻尔克, 15311 马奇诺防线] }]
点 15311 + 弃 4 张 →
  【英国】弃置 4 张手牌
  【英国】打出《马奇诺防线》—— 该法国陆军本回合不会被移除
  【法国】在 西欧 建设 1 支陆军           ← 法国陆军回到<西欧>，protect 修正登记
```

即：
- armed 窗口 **owner = 英国**（不是法国），英国玩家点得到；
- 弃 4 张代价走 `echo_discard_modal`（`confirm_echo_discard` 的 `armed` 分支 → `use_armed_offer{card, drop}`）；
- 弃不够 4 张会被明确拒绝且不消耗手牌。

**所以"英国打不出"的真实场景是：玩家在自己回合点手牌里的它** —— 那是按 B 的正确拒绝，
只是旧文案说"是响应卡，由触发事件驱动"，读起来像卡坏了。

## 2. 本次改动（2 处，均只改文案/提示）

```

            （<西欧>的法国陆军将被移除时：使其本回合内不会被移除），不能主动打出
响应卡     → 原文案不变（"是响应卡，由触发事件驱动，不能主动打出"）
```
