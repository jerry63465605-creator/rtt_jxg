## 3. 美国组特色（实现效果时注意）

1. **ECON 重炮（10 张，全[轰炸行动]）**：燃烧弹轰炸损耗 8 张、B-29 损耗 6 张，
   远超英国组（损耗 2-3 张）；地区要求「<日本>2/3 地区内有美国陆军/海军」。
2. **曼哈顿计划链**：STATUS 曼哈顿计划（弃牌阶段弃手牌得1分）+
   ECON 小男孩&胖子（场上有[曼哈顿计划]才能打出，损耗7+移除大本营陆军+得2分）
   ——跨卡 combo，实现时状态存在性查询。
3. **石油禁运**：所有敌方玩家**依次**选择（损耗2牌 或 被移除1支部队）——
   多人交互（同 ECON 让权链 pe.chain 模式）。
4. **中立机制**：现购自运「美国结束中立」、大萧条的余波（结束中立时弃置此牌
   得计分标记）、172 隔离演说（[除非…]美国结束中立）——美国开局中立，
   「结束中立」是状态翻转动作，与现有六国轮转 active 的关系**待设计**。
5. **大萧条前奏子体系（172）**：振兴公共事业/整顿经济/炉边谈话/民间资源保护
   均带[持续][大萧条]标签，可弃置[大萧条]+手牌 X 张触发追加效果；
   175 大萧条的余波/曼哈顿计划与之联动。前奏卡打出后**持续在场**（新载体）。
6. **中国子体系（计入美国）**：飞虎队（中国部署空军/夺制空）、滇缅公路、
   美国人民同情中国（中国陆军后备——「后备」概念首现）、抗日义勇军（日本
   弃+损耗）、重庆国民政府（**中国大本营迁移**：中国东部被占→改中国西部，
   同 15344 法国流亡政府 home_override 机制）、花园口决堤×2（168 EFFECT 版
   损耗2牌消灭占领军 / 172 ARMAMENT 版自动消灭——同名两版语义不同，
   实现时按 id 区分）。
7. **盟军远征部队最高司令部**：英法美**互相**连接补给线/海军以对方陆军为港
   ——多国混合补给规则，直接影响 compute_supply 的友军判定，优先级高。
8. **四巨头上将（168）**：建设/发起后追加一次同类型行动（复用 15339 英国
   皇家海军的 after_naval 窗口模式），名字命名统一的通用模板。
9. **战俘/曼哈顿计划计分**：战俘按"本回合被移除敌军数"计分——需要
   移除事件计数器（game.removed_this_turn）。
10. **B-25 米切尔**：打出后**置入英国手牌改为{英国}**——卡牌所有权转移，
    首次出现（{美国}/{英国}花括号标记国家变量）。
