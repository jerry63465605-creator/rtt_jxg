# 单位共存与攻击限制（Unit Coexistence）

> 版本 v1.0 · 2026-09-22 · 状态：**已实现并测试通过（17 项）**

---

## 1. 三条规则（2026-09-22 确认）

### 规则 1：同格位不能有敌方部队

一个格位上只能存在**同一阵营**的单位。敌方（不同阵营）部队不能进入已有我方部队的格位，反之亦然。

### 规则 2：每格位容量 —— 每国 1 个单位 + 1 个飞机

同一格位上：

- 同一阵营的**每个不同国家**各最多 **1 个「单位」**（陆军或海军）
- 每个**对应国家**各最多 **1 个「飞机」**（空军）

**示例**（北海，轴心国控制时）：

```
✓ 德国海军×1 + 意大利海军×1 + 德国空军×1 + 意大利空军×1
✗ 德国海军×2                    （同国单位超 1 个）
✗ 德国空军×2                    （同国飞机超 1 个）
✗ 英国海军×1                    （敌方阵营）
```

> 注：因地形限制（陆军只上陆、海军只下海），同一国家的「陆军+海军」
> 不会出现在同一格位。实现上仍按"非空军类合计最多 1 个"处理，
> 以防未来加入移动规则后出现漏洞。

### 规则 3：陆战/海战不能选择有我方阵营单位的地区

攻击目标必须是**纯敌方**地区——不能有任何我方阵营（含友军）单位。
这也意味着**发起单位必须在相邻格位**，不能与目标同格。

```
发起单位在【相邻格位】，目标格位【只有敌方】
```

## 2. 实现

### 2.1 单位槽位检查

```javascript
function unit_slot_free(game, nation, type, space)
```

统计该国在该格位上的非空军/空军数量，按类型返回是否还有空位。
被 `build_piece()` 调用，也导出供测试。

### 2.2 战斗目标校验（`do_battle`）

校验顺序：

1. 目标地形匹配（陆战→陆地，海战→海域）
2. **目标格位不能有任何我方阵营单位** ← 规则 3
3. 相邻格位有处于补给状态的同国陆/海军

> 2026-09-22 补充：**第 3 条"必须有敌方部队"已取消**。无人占领的空地同样是合法
> 战斗目标（"空打"），只是没有可移除的单位，仍消耗 1 行动点。详见
> `docs/basic-cards.md`。

### 2.3 `basic_targets` 的目标筛选

战斗卡的可选目标会**排除**任何有我方阵营单位的地区，
因此 UI 上根本不会高亮这些地区。

## 3. 与补给规则的关系（易混淆点）

海军补给的两条条件口径不同，容易被误认为互相矛盾：

| 条件 | 口径 | 说明 |
|---|---|---|
| 第 1 条（补给链） | **严格本国** | 意大利海军**不能**借德国陆军的补给链 |
| 第 2 条（临海） | **允许友军** | 但第 1 条不满足时，整体仍然断补 |

**实测结论**：北海上有德国陆军（在西欧，有补给）+ 德国海军 + 意大利海军时：

```
德国/navy=true      ← 邻接本国陆军，第1条满足
意大利/navy=false   ← 补给链不跨国家，友军不算
```

意大利海军要获得补给，必须有**意大利自己的**补给链
（如意大利陆军在其大本营，海军邻接它）。

## 4. 测试

```powershell
node tools/test_coexist.js     # 17 项
```

覆盖：
- 同格位不能有敌方部队（英军不能进德军格位，意军可以）
- 每国每格 1 单位 + 1 飞机（海军重复被拒、空军独立槽位、同阵营多国可共存）
- 战斗目标必须纯敌方（有我方单位被拒、纯敌方可行）
- 发起单位不能在目标格
- `basic_targets` 排除有我方单位的地区
- 友军共存（4 支单位同格）+ 补给分工验证
- 敌方单位使格位不可建设

### 4.1 测试踩坑

写海战用例时容易把敌我海军放在**同一格位**（北海），
这在旧规则下能过，但按新规则"同格位不能有敌方"，
这种局面**本身就不合法**，战斗必然被拒。

正确做法：我方海军在北海，敌方海军放在**相邻海域**
（如南大西洋），攻击那个相邻海域。

## 5. 影响的既有行为

| 行为 | 旧 | 新 |
|---|---|---|
| 两支海军同格交战 | 允许（含本格判定） | **禁止**（目标须纯敌方） |
| 发起单位与目标同格 | 允许 | **禁止** |
| 同国同类型重复建设 | 拒绝 | 拒绝（改由槽位检查统一处理） |
| 同阵营多国同格 | 允许 | 允许（明确为每国各 1 个） |
