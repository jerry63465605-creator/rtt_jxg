## 1. 规则原文

### 苏联

- 开局时，苏联对**德国和意大利**保持中立
  - 中立的苏联**不可以对德、意发动战斗或夺取制空权**
    - 但可以执行卡牌效果中的"消灭"
  - 中立的苏联每有 1 支部队**位于或邻接〈印度〉**，
    在**英国的计分阶段扣 1 分**
- 满足以下条件**其中之一**，苏联结束中立：
  - 苏联被德国或意大利攻击
  - 在苏联的回合开始时，有**至少 3 支**德国或意大利的海军或陆军与苏联部队相邻

### 美国

- 开局时，美国对**所有轴心国**保持中立
  - 中立的美国**不可以对轴心国发动战斗或夺取制空权**
    - 但可以执行卡牌效果中的"消灭"，也可以打出和执行【经济战】
  - 中立的美国**不允许在〈不列颠群岛〉建设或征召部队**
  - 中立的美国**不允许在〈奥斯陆〉或其相邻地区建设或征召部队**
- 满足以下条件**其中之一**，美国结束中立：
  - 美国被轴心国攻击
  - 轴心国占领了**除其自身大本营以外的至少 3 个补给点**
    - 包括仅对同盟国视为补给点的〈波兰〉〈中国西部〉〈非洲南部〉
      〈西伯利亚〉和焦土后的〈乌克兰〉
  - **进入第 10 回合**

> 其中两条消歧约定与本文档相关：
> - **日耳曼 = 德国**（id=44）："德国"是势力名，指地块时用"日耳曼"
> - **法国地块用西欧**（id=6）：法国大本营在西欧，地图上无"法国"地区

规则书写的是历史地名，本作地图是压缩过的抽象版，需做映射：

| 〈中国西部〉 | 中国西部 | 19 | 一致，但初始 `supply=false` |
| 〈非洲南部〉 | 非洲南部 | 31 | 一致，但初始 `supply=false` |

| 〈乌克兰〉 | 乌克兰 | 45 | 初始 `supply=true`；"焦土后"状态待确认 |

> **重要（玩家 2026-09-23 口径）**：
> 上表中初始 `supply=false` 的地区（波兰=东欧、中国西部、非洲南部、西伯利亚）
> **并不是"规则漏标"** —— 它们**本来就不是**补给点，
> 只有**卡牌效果**才能让它们变成补给点（或让补给点失效）。
>
> 因此实现里的 `EXTRA_ALLIED_SUPPLY_NAMES`
> （无条件把这些地区计入"轴心占领了几个补给点"）是**错误的**，
> 应改为运行时动态判定。详见 `docs/supply-points.md`。

## 3. 数据模型

### state 字段

```js
{
  neutral: { '苏联': true, '美国': true },   // true = 仍中立；false = 已参战
  neutral_reason: {},                        // nation -> 参战原因文案
}
```

**为什么用"名单 + 布尔"而不是一个 `is_neutral` 全局标志：**
中立是**逐国**的（苏联中立不等于美国中立），
且"谁对谁中立"是**方向性**的（美国对轴心中立，但美英之间本来就不是敌人）。
所以配置写成"敌对方名单"，限制检查与结束判定共用同一份配置。

### 配置表

```js
const NEUTRAL_RULES = {
  '苏联': { enemies: ['德国', '意大利'], no_build: [] },
  '美国': {
    enemies: ['德国', '意大利', '日本'],
    no_build: ['不列颠', '北欧'],
    no_build_plus_neighbors: ['北欧'],       // "奥斯陆【或其相邻地区】"
  },
}
```

将来加第三国只需改这张表，不必改逻辑。

## 4. 实现要点

### 4.1 限制入口

| 限制 | 接入点 | 函数 |
|---|---|---|
| 不可发动战斗 | `do_battle` 选定 `victim` **之后** | `neutral_attack_check` |
| 不可空打 | `do_battle` 的 `!enemies.length` 分支 | 同上（静态拦截） |
| 不可夺取制空权 | `seize_air` 选定目标后 | `neutral_attack_check` |
| 不可建设/征召（美国禁地） | `can_build_at` 最前面 | `neutral_build_check` |

**为什么战斗检查放在"选定 victim 之后"**：
中立限制是**按目标国籍**判的，而目标国籍只有在 `victim` 确定时才知道。
放在最前面无法判定。代价是空打路径要单独做一次静态拦截
（空打没有目标，但"发动战斗"这个动作本身照样被禁止）。

### 4.2 结束中立的触发点

| 触发 | 位置 |
|---|---|
| 被攻击（战斗） | `do_battle` 结算尾部 `maybe_end_neutral_by_attack` |
| 被攻击（夺取制空权） | `seize_air` 结算尾部，同一个函数 |
| 回合开始时相邻 3 支德/意陆海军 | `advance_phase` 国家轮转后 `check_neutral_end_on_turn` |
| 进入第 10 回合 | 同上 |
| 轴心占 3 个补给点 | 同上 |

**为什么"被攻击即参战"要放在结算尾部而不是开头**：
前面还有一大堆前置校验（地形、补给、相邻、空军代受挂起等）。
若在开头就参战，那些校验失败时"这次攻击其实没发生"，
却已经把国家改成参战状态了 —— 状态被污染。
放在"目标确实被移除/代受"之后才准确。
（挂在 `defend_air` 分支和普通移除分支**两处**，因为这是两条独立的成功出口。）

### 4.3 印度扣分

在 `phase_scoring(game, '英国')` 内结算：

- 只对**英国**的计分阶段生效（避免每个同盟国回合都扣一遍）
- 扣的是**英国所属阵营（同盟）**的分，不是单独记给英国
- 苏联参战后自动停止（`soviet_india_penalty` 内部判 `is_neutral`）

实现引入了 **`net = total - indiaPenalty`** 的净值概念：
`game.score` / `last_scoring.total` / `phase_note` / **函数返回值全部用 `net`**。
（曾经漏改返回值，见 `docs/pitfalls.md` 通用教训 14。）

`last_scoring` 现在同时带 `total`（净值）与 `gross`（毛分），便于排查。

### 4.4 向后兼容

`ensure_neutral(game)` 与 `ensure_markers` 一样，
在 `view` / `action` / `query` 三个入口调用，给老对局补 `neutral` 字段
（缺省按"开局中立"，与初值一致）。
