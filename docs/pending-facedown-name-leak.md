# 【已实施】暗置/未发动卡牌的牌名保密（出牌流水 + view 双通道）

> 状态：**已实施**（2026-10-25 批次 C），待部署后新局验证
> 回归脚本：`tools/_smoke_facedown_privacy.js`（20 项，全通过）
> 触发反馈：线上出牌流水出现
> - `#224 …打出响应《KV-2 重型坦克》（背面向上置于桌面，等时机触发）`
> - `#223 …放弃发动响应（《保卫祖国》留于桌面）`
> - `#98 …打出增强《御前会议》—— 弃置 1 张响应牌，暗置打出《全面侵华》`

## 一、口径

**只要牌面对对手保密，日志与 view 都不得写出卡名**，包括以下表态结果：

1. 出牌阶段打出响应卡（背面向上桌面）
2. 放弃发动响应（留于桌面）
3. 增强窗口建立时的"可打出"提示

判据统一为一句：**这张牌此刻是否对对手可见**（而不是"是否好玩/是否详细"）。
- 不可见 → 只写「张数 / 国家 / 阵营」
- 可见（已打出、已翻开结算、桌面状态卡、弃牌堆）→ 照旧写卡名

## 四、复核：是否过严

回归脚本已固化"不误伤"断言（全通过）：

- `仅 candidates 非空的帧`（已翻开）→ 对手**仍能看到**卡名
- `持有方自己`看到的一切照旧（`response_pending.name` / `response_stack.name` / `intercept` 完整记录）
- `owner_side` / `mine` 双方都下发，客户端仍可据此让位、显示"等待对方"

一句话：**只对对手隐藏，对本方不减配**。

## 七、遗留（与批次 C 无关，另行处理）
