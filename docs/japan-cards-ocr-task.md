## 2. 日本组特色（与德/英组的差异，实现效果时注意）

1. **EFFECT 代价体系不同**：日本 EFFECT 的代价多为「弃置1张[响应卡]」
   （大日本帝国海军/南云忠一/山本五十六/武士道/夜间运输/御前会议/诸岛要塞），
   而非德国的「损耗1张牌」——说明[响应卡]是可被当作资源消耗的卡类。
2. **RESPONSE 特别多（25 张）**：远超英国组（12）与德国组（0）。
   触发窗口集中在「出牌阶段开始时」（9 张）与「发起XX后」（8 张），
   实现时与英国 RESPONSE 的触发枚举对齐即可复用机制。
3. **前奏牌堆（184）新机制**：
   - `[紧张度-1]`（负紧张度动作：仆从国军、日苏中立条约、伪满洲国）
   - 「前奏牌损耗」：非暴力不合作运动令**英国**损耗前奏牌；天津事变日本自损
     前奏牌 → 前奏牌堆是可被攻击的资源池
   - 「陆军后备」（仆从国军）——新概念，未见规则书定义，**待用户解释**
   - 跨前奏堆引用：日苏中立条约「从苏联前奏牌堆打出[苏日中立条约]」
     （苏联卡组尚未识别，卡名引用即可，无需苏联数据先行）
   - `[持续]` 标记（九一八事变、日苏中立条约）：打出后留场持续生效
4. **同名不同卡**：「卢沟桥事变」（15429 RESPONSE / 18405 PRELUDE）、
   「伪满洲国」（15434 RESPONSE / 18410 PRELUDE）——CSV 允许重名，
   按 card_id 区分；UI 显示需带 id。
5. ECON 混用标签：封锁海参崴/印度洋警备队/轰炸重庆**无**[潜艇行动]标签，
   潜艇支援太平洋诸岛**有**——实现 ECON 标签过滤时按卡面原文。
