### 术语：损耗（attrition）

军需官系列核心机制：**"损耗 N 张牌" = 该国（玩家）弃 N 张手牌**。
与"弃置"（自己主动弃）区分。实现 ECON 时需要新增"损耗"动作
（对方玩家被迫弃牌，交互式选择弃哪些）。

### 标签：[轰炸行动] / [潜艇行动]

卡面方括号标签是**经济战行动类型**。已确认联动：15329 反潜战术（RESPONSE）
的触发条件是"[经济战]被打出时：使其无效"——即这两张卡（含挂起的 15349）
被打出时可被 15329 响应拦截。实现时 `resolve_econ_card` 要挂响应钩子
（同 R13/R21 的 request_responses 模式）。
