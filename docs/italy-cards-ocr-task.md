## 4. ⚠️ 识别错误复盘（↑/⇈ 混淆，2026-09-27）

**错误**：9 张 ↑ 增强卡被录成 ⇈ 状态卡（16700/16701/17705-17711），用户裁定改正。

**根因链（三层）**：

1. **形态层——意大利 ↑ 是"粗胖变体"**：三角头宽 30px + 粗杆宽 30px，头杆
   过渡处宽度曲线出现"收窄(y60-66 到 20-24)→回升(y67+ 到 30)"，与真 ⇈
   （Flak-40 两个分离斜箭头）的宽度曲线**几乎同形**。宽度 profile 是间接
   信号，区分不了"一个粗箭头的阶梯过渡"和"两个分离箭头"。
2. **肉眼层——小图错觉+批量先入**：380px 小图上，粗胖单箭头的头部/杆阶梯
   视觉上像"两个白块叠放"；且意大利组一图多卡（r0/r1 用 279 潜艇海报、
   r4 用母狼海报），第一次读图把 r0 的单箭头看成与母狼组一致后，
   **20 张全部按 ⇈ 批量录入**，个别差异被整组假设掩盖。
3. **校准层——校准样本形态多样性不足**：像素脚本用 15305（瘦长↑，峰值48）
   校准"单箭头"，但意大利↑是粗胖变体（峰值30+平台30），与校准样本差异
   大；瘦高⇈（15338）又被漏判成 SINGLE——两种变体都不在校准集里，
   "下降事件≥2"判据两头都会错。
4. **语义线索被忽略**：16700 一日之狮文本明写「敌方国家打出**[增强卡]**时」
   ——组内存在增强卡体系的最强提示，未据此回头复查图标。

**正确判别法（沉淀）**：⇈ 的定义特征是**两个箭头空间分离**（对角错位、中间
有背景隔断），不是宽度曲线。像素法只能做初筛（DOUBLE 可信、SINGLE 存疑），
**终审必须放大 3x+ 肉眼比对已知真值**（15305=↑、Flak-40=⇈），对照卡要覆盖
胖/瘦两种变体。工具：`tools/zoom_icons.ps1`（裁剪图标区放大拼网格）。

**适用范围**：苏联/日本 EFFECT 卡已放大抽查确认无误（178_r0_c5、178_r1_c0
为清晰单箭头）；但将来识别新国家时，所有 ↑/⇈ 卡必须过一遍 zoom 终审，
不能靠小图肉眼或宽度曲线直接定类型。
