## 通用行动卡（无图标）

第 0 行的 5 张卡是各国共有的"基本行动卡"，**无类型图标**：

- 建设陆军
- 发起陆战

这些卡在 RTT 中可作为 `type = "BASIC"`（基本卡）。

## 判定方法

卡面**右上角**的图标决定类型。识别时优先看右上角：

```
┌─────────────────────┐
│ 卡名            [图标] │  ← 右上角图标 = 类型
├─────────────────────┤
│                     │
│       插图          │
│                     │
├─────────────────────┤
│ 效果文本             │
└─────────────────────┘
```

### 可靠的识别手段：像素签名

`tools/analyze_icons.ps1` 取卡图右上角区域
（x ∈ [0.72w, 0.97w]，y ∈ [0.02h, 0.20h]），
降采样成 6×8 网格，每格按白色像素密度输出 `# + - .`。
同图标的卡会得到**相同签名**，据此聚类即可判定类型。

已验证的签名（2026-09-23，对 54 张卡实测）：

| 签名 | 图标 | 类型 |
|---|---|---|
| `..-+-./..#-#./..-.#./...#-./...+../...+../...-..` | `?` | RESPONSE |
| `...+../...#../...#../...#../....../...#..` | `!` | EVENT |
| `...+../...#../...#../...#../....../-+.#.+/+#+.##` | `!` | EVENT |
| `...+../..+#+./.+###-/.-.#--/...#../...#..` | `↑` | ECHO |
| `...+../..+#+./.+###-/.--#--/...#../...#..` | `↑` | ECHO |
| `...--./..+##+/.+###./.###-.` | 兵器 | ECON |
| `...+../..+#+./.-#-#-/..+#+./.-#.#-/...` | `⇈` | STATUS |
| `...+../..+#+./.-#+#-/..+#+./.-#.#-/...` | `⇈` | STATUS |

形状直觉：`!` = 细竖线 + 下方断开的点；
`↑` = 顶部实心三角(`###`)渐收 + 下方竖杆；
`?` = 上方向右下的曲线；`⇈` = 两组 `{-#-#-}` 山形重复。

### 命名统一说明

- 本文件的 `ECHO` 与 `CARD_TYPE_INFO` 的 code **`EFFECT`** 指**同一个类型**
- **代码里一律用 `EFFECT`**（历史原因，改动面太大）
- 文档中两个名字都保留并互相注明
- `CARD_TYPE_INFO.EFFECT` 的描述已从错误的"效果卡/持续生效"
  修正为"**增强卡**：对应时机打出，置入弃牌堆并执行效果；不占出牌名额"
