## 1. 核心概念与术语

| 术语 | 定义 |
|---|---|
| **阵营（side）** | 轴心国 / 同盟国，两个玩家位 |
| **国家（nation）** | 德/英/日/苏/意/美/中/法，共 8 个 |
| **军种（type）** | 陆军（army）/ 海军（navy）/ 空军（air） |
| **格位（space）** | 地图上的区域，含邻接关系 |
| **补给点（supply）** | 带 ★ 的标志地区，计分与补给的来源 |
| **补给状态（in supply）** | 算子能否行动的前提 |
| **大本营（home base）** | 国家的本土核心区 |
| **海峡（strait）** | 5 个特殊陆地格位，控制权决定其两侧海域是否连通 |
| **手牌（hand）** | 上限 7 张 |
| **紧张度（tension）** | 前奏期专用标量，初始 0，达 10 触发结束 |

### 1.1 国家与阵营 【待定】

从规则书的行动顺序可以确认 6 国：

```
德国 → 英国 → 日本 → 苏联 → 意大利 → 美国
```

但算子清单里出现了 **8 个国家**（多了中国、法国），且规则书提到：

- 第 4 页：美国"在英国的计分阶段也计算法国的得分；在美国的计分阶段也计算中国的得分"
- `join_war.png`：中国出现在 `<中国东北>`、`<中国西部>` 地区名中

**推断的阵营划分**：

| 阵营 | 国家 | 行动顺序 |
|---|---|---|
| 轴心国 | 德国、日本、意大利 | 德(1) 日(3) 意(5) |
| 同盟国 | 英国、苏联、美国 | 英(2) 苏(4) 美(6) |
| 附庸/被计入 | 法国（随英国）、中国（随美国） | 无独立回合 |

`【待定 1】` 法国和中国是否作为**独立可操作国家**，还是纯作为计分/地区归属存在？这决定 `roles` 是 2 个还是 8 个。

## 2. 数据结构设计

### 2.1 格位（spaces）

对应 RTT 的 `layout.js` + `data.js` 的 `spaces`。

```javascript
// 每个格位的属性
{
    id: "germany",              // 唯一标识
    name: "德国",               // 显示名
    nation: "germany",          // 归属国（用于建设限制）
    terrain: "land",            // land | sea
    supply: true,               // 是否为补给点（★）
    home_base: ["germany"],     // 哪些国家以此为本土
    neighbors: ["poland", ...], // 邻接格位 id
    strait: null,               // 海峡标记（5 个特殊格位）
    x: 120, y: 340, w: 60, h: 40,  // 布局坐标（从 229 个 SnapPoints 映射）
}
```

**数据来源（已定稿）**：`out/spaces_calibrated.json` —— 53 个格位（陆 38 / 海 15），
经交互式标定页人工确认坐标与属性（`terrain` / `supply` / `home` / `strait`）。

**邻接关系（已定稿）**：137 条连线（普通 132 / 有限 1 / 海峡 4），
经 `tools/link_editor.html` 人工绘制，编译产物为 `out/adjacency.json`。
详见 `docs/connectivity.md`。

> 注：不再使用 SnapPoints 坐标（吸附点与地图格位无关）。

### 2.2 算子（pieces）

对应 RTT 的 `data.js` 的 `pieces` + `pieces/*.webp`。

```javascript
{
    name: "德国陆军",           // 唯一名
    nation: "germany",
    type: "army",             // army | navy | air | reserve | home_base
    supply: true,             // 编制状态（可被"移除"改为 false）
    count: 5,                 // 该国该军种的最大数量
}
```

**从素材提取的真实清单**（29 种）：

| 军种 | 国家 | 数量 |
|---|---|---|
| 陆军 | 中/德/意/日/法/美/苏/英 | 8 种 |
| 海军 | 德/意/日/法/美/苏/英 | 7 种（**无中国**） |
| 空军 | 德/意/日/法/美/苏/英 | 7 种（**无中国**） |
| 预备役 | 中国陆军/意大利陆军/日本陆军/美国空军 | 4 种 |
| 大本营 | 中国/法国/苏联 | 3 种 |

`【待定 3】` 每个算子的 `count`（初始数量）需要你确定。原版军需官系列通常每国 3-5 个陆地单位。

> **2026-09-23 核对**：这一项**仍未确定**，代码里也**没有**棋子库存机制
> （`game` 里没有任何 stock / reserve / pool 字段）。
> 影响到的功能：
> - easy_rule 五.1「收回本国棋子」（已实现，不受库存限制）
> - easy_rule 五「征召部队」（**未实现**，依赖库存）
> - 建设时是否受"该国该军种剩余数量"限制（**未实现**）
>
> 参考值：原版军需官系列通常每国 3-5 个陆地单位。
> 需要玩家给出每种算子的具体 `count` 后才能实现库存与征召。

### 2.3 卡牌（cards）

对应 RTT 的 `data.js` 的 `cards` + `cards.1x/*.avif`。

**5 种卡牌类型**（规则书第四节）：

| 类型 | 打出时机 | 效果 |
|---|---|---|
| **基本卡** | 出牌阶段 | 无文本框（用于弃牌/经济） |
| **事件卡** | 出牌阶段 | 打出后弃置，执行效果 |
| **经济卡** | 出牌阶段 | 打出后弃置，执行效果 |
| **状态卡** | 出牌阶段 | **正面向上置于桌面，效果持续** |
| **响应卡** | 对应时机（含对手回合） | 背面向上置于桌面，可触发 |
| **增强卡** | 对应时机 | 打出后弃置并执行效果 |

**素材现状**：
- 25 张雪碧图（每张 10×7 = 70 张卡位）
- 164 个卡牌对象
- 4 个国家有"响应卡计数器"：**日本、意大利、苏联、英国**

`【待定 4】` **卡牌数据需要人工录入**。雪碧图只是图片，具体的卡名、类型、效果文本需要：
- **方案 A**：从 mod 的 Lua 脚本提取（如果有卡牌定义表）
- **方案 B**：你手工提供牌表（Excel/CSV）
- **方案 C**：从雪碧图上逐张抄（工作量大）

**最小子集建议**：先只做**基本卡 + 事件卡**两类，每国 7-10 张，共约 50 张。

### 2.4 全局状态（game state）

RTT 的 `setup()` 返回的 game 对象：

```javascript
{
    seed: 12345,
    log: [],                 // 动作日志
    undo: [],                // 撤销栈
    active: "germany",       // 当前行动国

    turn: 1,                 // 回合数
    phase: "resource",       // 当前阶段
    tension: 0,              // 紧张度（前奏期）
    score: { axis: 0, allies: 0 },
    is_prologue: true,       // 是否在前奏期

    players: {
        axis:   { nations: ["germany", "japan", "italy"], hand: [], deck: [], discard: [] },
        allies: { nations: ["uk", "ussr", "usa"],        hand: [], deck: [], discard: [] },
    },

    pieces: {},              // 算子位置 { pieceId: spaceId | null }
    spaces: {},              // 格位占位情况 { spaceId: [pieceId, ...] }

    permanent_cards: [],     // 已放置的状态卡
    response_cards: [],      // 已放置的响应卡
}
```

## 3. 回合流程（状态机）

规则书第二节定义了 7 个阶段。在 RTT 中用 `script()` 的状态机实现：

```
回合开始
  │
  ├─ 1. 资源再分配：弃 3 张手牌，从牌堆挑 1 张基本卡入手，洗混牌堆
  │
  ├─ 2. 出牌阶段【必做】：打出 1 张手牌 | 弃 1 张手牌 | 减 1 分
  │
  ├─ 3. 空军阶段：打出【空军力量】 | 弃 1 张手牌调度 1 支空军
  │
  ├─ 4. 补给阶段：移除当前回合国不处于补给状态的部队
  │
  ├─ 5. 计分阶段：计算当前回合国得分
  │      （若大本营被占，跳过）
  │      · 独占领补给点 +2
  │      · 与友军共同占领 +1
  │      · 英国计分时也算法国；美国计分时也算中国
  │
  ├─ 6. 弃牌阶段：可弃任意数量手牌
  │
  └─ 7. 摸牌阶段：摸至 7 张（牌堆空则跳过）
```

**行动顺序**：德国 → 英国 → 日本 → 苏联 → 意大利 → 美国（每国一个完整回合）

`【待定 5】` 上表的 7 阶段是"每国执行一次"，还是"6 国依次各执行 1-2 阶段"？规则书写得像是**每国完整执行 7 阶段**，需要你确认。

## 4. 核心机制

### 4.1 补给（Supply）

**陆军补给条件**（满足其一）：
- 位于补给点（★）
- 与处于补给状态的本国部队相邻

**海军补给条件**（需全部满足）：
- 与处于补给状态的本国部队相邻
- 与本国或友军的陆地部队相邻

**实现要点**：这是一个**递归传播**算法（从补给点 BFS 扩散）。注意需要处理循环。

### 4.2 建设/征召（Build/Recruit）

条件（需全部满足）：
1. 有剩余的对应部队棋子
2. 目标地区：
   - 建设陆军/征召陆军 → 只能陆地；海军 → 只能海域
   - **不能有敌方部队、不能有本国部队**
   - 建设：地区必须位于本国大本营 **或** 邻接处于补给状态的本国部队
   - 征召：置于该地区的新部队将处于补给状态
3. 放置对应的陆军/海军算子

**额外规则**：任意玩家可在任意时刻收回版图上的本国部队。

### 4.3 战斗（Combat）

1. 选 1 支处于补给状态的本国部队（陆军或海军）
2. 选该部队相邻的地区：
   - 陆战只能选陆地，海战只能选海域
   - 可选**无人占领**的地区
   - **不能**选被本国或友军占领的地区
3. 移除该地区 1 支敌方部队

`【待定 6】` 原版军需官有"战斗骰"机制，这份简化规则**没有骰子**（直接移除）。确认是纯确定性战斗？

### 4.4 空军（Air Force）

- **空军阶段**可打出【空军力量】执行：
  - **部署空军**：选 1 支处于补给状态的本国陆军或海军，在其所在地区放置空军算子
  - **夺取制空权**：选 1 支本国空军，移除邻接的 1 支敌方空军
  - **调度空军**：选 1 支本国空军，选处于补给状态的本国陆军或海军，将前者移动到后者所在地区（同一地区不允许存在多支同一国家的空军）
- 当与空军位于同一地区的本国部队被发起战斗时，可移除此空军来代替移除受到攻击的部队；战斗发起方可移除 1 支相邻的空军来抵消
- 当与空军位于同一地区的本国部队被移除后，**必须**调度此空军或移除此空军

### 4.5 海峡（Straits）【已确认 2026-09-21】

- 共 **4 个海峡**，标记在**陆地格位**上（不是海上航线）

| 海峡陆地 | 所在格位 | 默认归属 | 打通的两片海域 |
|---|---|---|---|
| 丹麦海峡 | 北欧 | **轴心国** | 北海 ↔ 波罗的海 |
| 直布罗陀 | 非洲北部 | 同盟国 | 地中海 ↔ 北海 |
| 土耳其海峡 | 中东 | 同盟国 | 阿拉伯海 ↔ 地中海 |
| 巴拿马运河 | 拉丁美洲 | 同盟国 | 北大西洋 ↔ 东太平洋 |

- 控制判据：**只要该陆地格位上有某阵营的部队，该阵营即控制此海峡**
  - 单位归属按国家 → 阵营映射（德/日/意为轴心；英/法/苏/美/中为同盟）
  - 因此"是否为该国大本营"不影响海峡控制
- 控制权唯一：同一处不会同时存在双方部队（建设/征召要求目标格位无敌方部队且无本国部队），
  同一格位只会属于一个阵营
- **开局默认归属**见上表（尚无部队时生效；有部队时以部队归属为准）
- 效果：海峡所连两侧海域，对**控制方**视为**相邻**（可通行、可补给、可战斗）；
  对另一阵营视为**不相邻**
- 该连通是**阵营私有**的：轴心国拥有、同盟国不拥有的航道，只对轴心国的补给/战斗/移动生效

> **实现注意**：海峡线记录的是"被此海峡隔开的那一对海域"，
> 其余海域之间的普通连通**不受海峡控制权影响**。只有 `strait: true` 的格位参与动态开关。
>
> 详细算法、数据格式与编译产物见 **`docs/connectivity.md`**。

### 4.6 计分（Scoring）

- **回合内**：独占领补给点 +2；与友军共同占领 +1
- **终局胜利**：20 回合结束后，轴心国获得 0.5 分，总分较高者获胜
- **即时胜利**：美国的计分阶段结束时，某阵营领先 ≥ 30 分，该阵营立即获胜

## 5. 前奏期（Prologue / 门前惊雷）

### 5.1 前奏规则

- 前奏期内**正式游戏手牌无法使用**（除非另有说明）
- 玩家按正常流程抽取正式游戏手牌，**然后摸 2 张前奏牌**
- `<东欧>`、`<巴尔干>`、`<中国东北>` **不增加计分标记**
- **正式牌堆变动**（见 B 节）

### 5.2 前奏流程

按正常游戏顺序执行回合，但每回合的阶段缩减为：

```
行动阶段（二选一，不可跳过）：
  · 打出 1 张手牌
  · 打出牌堆顶的牌
  · 弃置 1 张前奏手牌和牌堆顶的牌，然后再执行 1 次行动阶段

卡牌阶段（按顺序执行，不可跳过）：
  · 弃置所有前奏手牌
  · 摸 2 张前奏牌
```

**注意**：
- 前奏中不执行分数与补给计算，但**建造和战斗仍需参考补给规则**
- 前奏牌堆的牌始终对自己可见
- 前奏中，**正式牌无法触发**，军备卡可以触发，可以使用国家技能

### 5.3 前奏结束

紧张度初始 0，被前奏卡牌影响（升高或降低）。

**三个结束时机**：
1. 一轮结束后，所有玩家的手牌和牌堆中都没有牌
2. 紧张度达到 10，当前前奏回合结束时
3. `【待定 7】` 规则书第 3 张截图在此处被截断，可能有第三个条件

### 5.4 卡牌变动（删除卡牌）

| 国家 | 删除的卡牌 |
|---|---|
| 日本 | 伪满洲国、卢沟桥事变 |
| 苏联 | 苏德友好条约 |
| 意大利 | 埃塞俄比亚战争后勤 |
| 美国 | 花园口决堤 |

## 6. 参战规则

### 6.1 苏联参战

**开局时**，苏联对德国和意大利保持中立：
- 中立的苏联**不可**对德、意发动战斗或夺取制空权（但可执行卡牌效果中的"消灭"）
- 中立的苏联每有 1 支部队位于**或邻接** `<印度>`，在英国的计分阶段扣 1 分

**结束中立条件**（满足其一）：
- 苏联被德国或意大利攻击
- 在苏联的回合开始时，有至少 3 支德国或意大利的海军或陆军与苏联部队相邻

### 6.2 美国参战

**开局时**，美国对所有轴心国保持中立：
- 中立的美国**不可**对轴心国发动战斗或夺取制空权（但可执行"消灭"效果，也可打出和执行【经济战】）
- 中立的美国**不允许**在 `<不列颠群岛>` 建设或征召部队
- 中立的美国**不允许**在 `<莫斯科>` 或其相邻地区建设或征召部队

**结束中立条件**（满足其一）：
- 美国被轴心国攻击
- 轴心国占领了除其自身大本营以外的至少 3 个补给点
  （包括仅对同盟国视为补给点的 `<波兰>` `<中国西部>` `<非洲南部>` `<西伯利亚>` 和焦土后的 `<乌克兰>`）
- 进入第 10 回合

## 8. 最小可玩子集（MVP）建议
