### 3.5 新增类型说明（德国组带来）

- **PRELUDE（前奏卡）**：效果含「打出1张前奏手牌」「前奏牌堆顶的牌」——存在
  独立的**前奏牌堆/前奏手牌**体系，且会「将1张[高速公路]/[枪支与黄油]洗入正式
  牌堆」（14902/14905 把 15228/15234 的卡从别处洗进 CORE——两张同名卡不同
  位置，实现时注意是"卡名引用"不是"卡 id 引用"）。
- **ARMAMENT（军备卡）**：由前奏卡打出（14903「打出1张[军备卡]」、14906），
  打出后持续生效（同 STATUS 语义，但图标/来源不同）。实现上可复用 STATUS 的
  载体（ongoing/trigger），外层挂 ARMAMENT 类型。
- **`[战略卡]`**：15234 枪支或黄油「可视作任意非[空军力量]的[战略卡]打出」——
  推测 BASIC 5 张 + 空军力量属于"战略卡"大类，待规则书确认。
- **`★` 星标**：出现在部分 EVENT/STATUS 上（阿登闪击战、海狮计划、土耳其加入
  轴心国、伊朗加入轴心国、提尔比茨号、大德意志帝国等）——语义推测为
  「每局限一次」，**未核实，实现前需玩家确认**。
- **BASIC 卡面无文本区**（只有插画+标题条）：规则书通用，effect_CN 沿用英国组
  文本，CSV read 列已标「沿用英国组文本（卡面无文本区）」。
- **斜体花絮**（如「德意志，启动！」「古不帅」「被封印的左手」）为卡面趣味文案，
  不录入 CSV（与英国组口径一致）。

## 4. 识别流程（四步）

1. **读图**：视觉模型（glm 5.3）逐格读
   `out/cards_sliced/sheet{152,66,145,149}_r{r}_c{c}.png`，每批 ≤8 张，
   按模板抄录：`卡名 / 图标类型 / ops / 效果全文`。
2. **填表**：写入 `out/de_cards.csv`，列结构与 `uk_cards.csv` 完全一致：
   `deck,card_id,sheet,row,col,name_CN,type,ops,effect_CN,img_file,read`
   - `read` 列填 `逐张`（核验状态），发现存疑标 `待核`。
3. **自检**：`node` 侧脚本核对——行数=87、card_id 连续无重复、
   img_file 都存在、type/ops 组合合法（BASIC/STATUS 无 ops，其余=1）。
4. **用户核验**：预览页德国标签下逐张对照卡图（§6），有误回改 CSV 重新生成。
