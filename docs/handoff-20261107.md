## 5. 测试手法铁律（省你重踩）

1. **布阵只用** `debug_set_phase` / `debug_place` / `debug_add_card`；驱动只用真实 action。
2. `debug_place` **静默失败**（地区/阵营不符时不报错）→ 布完必须 `pieces_on` 复查。
3. 事件卡多步：`play_card{card, spaces:[null, <id>]}` 预选；停住再 `event_step_next{}`。
4. 脚本卡：弃牌用 `resolve_script{discard:[...]}`、取牌用 `{pick:[...]}`；候选里 **`id` 才是实例 id**。
5. 计分：`phase_scoring` 只**暂存** `pending_scoring`，真正落账在 `next_phase`（scoring→discard 边界）；且标记本身也计分。
6. **海军可以发起陆战**（`battle_initiators` 接受 navy）；澳/新只邻海域，正靠海军登陆。
7. `play_start` 响应卡：先 `play_card` 暗置 → `debug_set_phase(resource)` → `debug_set_phase(play)` 才派发窗口。
8. 脚本卡候选走 `query 'script_state'`，**不在** `view.pending_script` 里。

## 8. 已知坑（都真踩过）

1. **中文路径/中文 JS 不能内联进 `node -e`**（PowerShell 会 GBK 弄坏）→ 一律写 `.js` 脚本或走环境变量。
2. `.ps1` 源码里出现中文会被 PowerShell 5.1 按 ANSI 读坏 → 脚本保持纯 ASCII，中文走 `$env:` 传入。
3. `debug_set_phase` 会把 `play_done` **重置回 true** → 中局快照里无法再 `play_card`。
4. 8091 只监听 `::1`，`127.0.0.1` 必拒。
5. `.codebuddy/` 只放行 `skills/`（`.gitignore` 已按此配置）；**不要删 `.codebuddy`**。
6. 老对局的牌堆是**旧构成**（不含 SUPP），只有新建对局才带 SUPP。
